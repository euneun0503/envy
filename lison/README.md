# 리손패키지 거래처·생산 관리 (ENVY 관리 프로그램 기반)

ENVY 관리 프로그램의 기능(대시보드·발주 입력·총정리·거래처원장·거래명세서·입금 관리·카드경비·세금 계산·간편장부·거래처·아침 요약 메일·작업의뢰서 전송)을 그대로 두고, **생산 일정만 리손 공정으로 바꾼 버전**입니다.

## 바뀐 점 (ENVY 대비)
- 공정: 발주 → **동판 → 원단 입고 → 인쇄 → 합지 1·2·3차 / 슬리터 / 가공** → 출고
- **품목별 생산**: 같은 날 같은 거래처의 품목이 여러 개여도 품목마다 일정·작업의뢰서가 따로 잡힘
- 작업 사양의 원단 1~4급지: 급지를 고르면 그 급지에 **지난번 쓴 원단 발주처**가 자동으로 채워짐(고칠 수 있음)
- 인쇄·합지 업체도 거래처별 지난 값이 기본, 같은 품목 재주문은 지난 사양을 자동으로 불러옴
- 작업 사양 저장 → 생산 일정의 원단 발주처·인쇄 공장·합지 차수·가공이 빈칸이면 자동 채움
- 동판 재사용(재판)이면 동판 단계만 생략, 동판 단계 업체 = 인쇄소
- 기본 색: 리손 그린, 로고: LITHON PACKAGE, 저장 키 `lison_` (ENVY와 같은 브라우저에서도 안 섞임)

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 앱 (GitHub에 올리는 파일) |
| `Code.gs` | 구글 시트 Apps Script 서버 코드 (새로 작성, 가짜 시트로 106개 항목 검증) |
| `리손패키지_총정리_테스트.xlsx` | 테스트 총정리 (구글 드라이브에도 '리손패키지 총정리 (테스트)'로 만들어 둠) |
| `리손패키지_작업의뢰서_양식.xlsx` | 빈 작업의뢰서 양식 — 채워서 앱에 올리면 주문이 생김 |

## 테스트 시트에 연결하기 (5분)
1. 드라이브의 **리손패키지 총정리 (테스트)** 열기 → 확장 프로그램 → Apps Script
2. `Code.gs` 전체 붙여넣기 → 저장 → 함수 **setup** 실행 → 권한 허용 → 실행 로그의 **비밀번호(API_KEY)** 복사
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 웹 앱 주소 복사
4. GitHub 앱 → 설정 → 웹 앱 주소·비밀번호 입력
5. 실제 총정리로 바꿀 때: 실제 시트에서 같은 방법(1~4)으로 하면 됨. 총정리 탭 이름은 `리손총정리` 또는 `총정리`, 3행에 발주일·업체명·품목… 열 제목(ENVY와 같은 구조)

## 작업의뢰서 엑셀로 발주 만들기
생산 일정 → **의뢰서 엑셀 올리기** → `.xlsx` 선택 → 거래처·단가 확인 → 저장
→ 총정리에 주문 줄, 작업 사양(원단 급지별 발주처·인쇄 색상·합지·가공·도안), 생산 일정이 한 번에 생김.
도안 그림은 `.xlsx`만 읽혀요(옛 `.xls`는 글자만). 사진·캡처 이미지는 엑셀이 아니라 읽을 수 없어요.

## 공장 정산 (공장별 지급 · 업무 정리)
- **공장 정산** 탭(휴대폰은 더보기): 공장마다 진행 중 공정 수·지연·다음 일정, 매입(공급가), **미지급(VAT 포함)**, 최근 지급일
- 공장을 누르면: 그 공장이 맡은 공정(동판·인쇄·원단 급지별·합지 차수·슬리터·가공, 예정/완료) + 총정리 매입 줄
- 매입 줄을 골라 **선택 지급 처리** → 총정리 시트 오른쪽 `지급확인·지급일·지급액` 칸에 기록 (지급 취소 가능)
- **단가 예정/확정**: 매입 줄마다 [수정]으로 내역(규격)·수량·단가·금액을 고쳐요(수량×단가 자동 계산). 처음은 **예정**, 정해지면 **확정**(칩을 누르거나 여러 줄 골라 [선택 단가 확정]).
  확정·지급된 줄도 고칠 수 있고, 이때는 사유를 받아 `일정변경이력` 탭에 "47,880×22=1,053,360 → 47,880×24=1,149,120 · 사유"처럼 남아요. 지급 뒤 금액이 바뀌면 차액을 표시해요. 총정리 시트의 같은 줄(매입수량·매입단가·매입금액, `단가상태` 열)이 바로 바뀌고 매입금액 수식은 그대로예요.
- **수정 기록**: 공장 정산·발주 입력·총정리 어디서든 매입처·품목(내역)·수량·단가·금액·예정/확정·지급이 바뀌면 시트 **매입수정기록** 탭에 한 칸씩 남아요 (수정 일시 · 거래처·발주일 · 항목 · 이전 → 변경 · 구분 · 사유). 공장 세부 화면 아래 '수정 기록'에서 봐요(엑셀 다운로드에는 넣지 않음).
- 값은 총정리의 그 줄 하나에만 있어서, 고치면 대시보드·총정리·이익·공장 정산·엑셀이 모두 같은 값을 읽어요.
- **세부 내역 받기 (매입처 원장 엑셀)**: 공장 정산 목록의 각 공장 줄 · 공장 세부 화면에 버튼. 거래처원장과 같은 모양으로
  공장 정보 · 전월 이월 미지급 · 전월 지급금 · 기간 매입/지급 · 기간말 미지급 · **현재 미지급금**, 본문(월일·적요(수량×단가)·공급가액·세액·매입금액·지급액·미지급 잔액·예정/확정), 월계·누계·합계. 기간은 공장 정산 위쪽에서 고른 기간.
  같은 파일에 시트 3개: **매입원장**(통합 정리) · **세부 내역**(발주일·거래처·제품·품목(내역)·수량·단가·공급가·세액·합계·예정/확정·지급일·지급액·미지급·출고일·비고, 필터) · **맡긴 공정**. 수정 기록은 엑셀에 넣지 않고 앱 화면과 시트 매입수정기록 탭에서만 봐요.
- **엑셀 받기**: 공장 정산 목록(전체) · 공장 세부(매입 + 맡긴 공정 2개 시트, 공급가·부가세·합계·예정/확정·지급일)
- **작업·정산 정리 복사**: 공장에 보낼 "진행 작업 + 미지급 내역" 문구를 카톡·문자에 붙여넣기
- 매입처 이름은 총정리 `매입처` 칸 기준. 공장 관리 이름과 같게 써야 작업과 정산이 한 줄로 묶여요.

## 단가가 그때그때 다를 때
총정리 한 줄 = 매출(수량·단가) + 매입(매입처·규격·수량·단가). **발주 입력 → 지난 주문 불러오기**를 하면 지난번 품목·매입처·단가가 담기고,
담은 줄을 눌러 원단비·인쇄비·가공비 단가를 고친 뒤 저장하면 **새 주문에만** 바뀐 단가가 들어가요(지난 주문은 그대로). 이익·매입처별 합계·거래처원장은 고친 값으로 계산돼요.
※ 작업 사양(작업의뢰서)의 업체를 바꿔도 총정리의 매입 줄은 자동으로 바뀌지 않아요. 매입 줄 업체·단가는 발주 입력/총정리에서 고쳐 주세요.

## GitHub → 카페24
지금 구조는 GitHub Pages(화면) + 구글 시트(데이터)라 카페24 없이도 여러 기기에서 같이 써요.
카페24로 옮길 때는 `index.html`만 카페24 웹 폴더에 올리면 되고, 데이터는 그대로 구글 시트에 남아요.

## 카톡 보내기 (거래처·공장별 톡방, 나에게 보내기)
- 거래처 정보와 공장 관리에 **카톡 채팅방 링크**(오픈채팅·채널)를 넣어두면, 원장·명세서·작업의뢰서의 **카톡** → **메시지 복사하고 카톡방 열기**로 그 방이 바로 열려요. 카카오톡은 다른 프로그램이 방에 글을 자동으로 올리는 걸 막아서, 열린 방에 붙여넣기만 하면 돼요.
- **링크 공유하기 (나에게·채팅방)**: 카카오톡의 받는 사람 고르기 창이 열려서 **나와의 채팅**이나 원하는 채팅방을 고르면 글이 채워져서 가요.
  - 휴대폰: 바로 됨 (공유 창 → 카카오톡 → 나와의 채팅/채팅방).
  - PC에서도 같은 창을 쓰려면 카카오 개발자 사이트에서 앱을 만들어 **JavaScript 키**를 카톡 창의 '카카오톡 공유 설정'에 저장하세요. 앱 설정 → 플랫폼 → Web 에 이 사이트 주소(예: https://아이디.github.io)와 https://drive.google.com 을 등록해야 해요.

## 공장 정산 기간 검색
- 시작일~종료일 직접 입력, **이번 달 · 지난 달 · 올해 · 전체** 버튼, **월별 선택 칩**(여러 달 체크 가능)
- 목록의 기간 매입, 세부 매입 줄, 수정 기록, 모든 엑셀(목록·세부·매입처 원장)이 고른 기간을 따라가요. '현재 미지급'은 기간과 상관없이 지금 남은 전체예요.
- 여러 달을 골라 원장을 받으면 빠진 달 자리에 '이월 (중간 달 제외)' 줄로 잔액을 이어 줘요.

## 직전 매입 단가 자동 불러오기
- 발주 입력에서 매입처와 품목(내역)을 넣으면 **같은 공장·같은 공정의 직전 단가**가 매입단가에 기본으로 들어가요(토스트로 어느 날 어느 줄 단가인지 알려줌). 직접 고치면 그 값이 우선.
- 같은 공정: 원단(재질+두께, 예 PET12·AL6·LLD70) · 인쇄(N도) · 합지(솔벤·드라이·무용제) · 슬리터 · 동판 · 택배 · 박스. 봉투·파우치 가공은 크기마다 달라서 같은 내역끼리만.
- 같은 내역의 지난 단가가 있어도, 그 뒤에 공장 정산에서 같은 공정 단가를 고쳤으면 고친 단가가 기본이 돼요. (예: 동성산업 인쇄 7도 22→24원 수정 → 다음 인쇄 7도 줄은 24원)
- **지난 주문 불러오기**도 담을 때 매입 단가를 직전 단가로 바꾸고 몇 줄 바꿨는지 알려줘요.

## 공장 관리
- 검색(이름·공정·담당자·전화·이메일), 공정 버튼(전체·원단·인쇄·합지·슬리터·가공, 개수 표시), 썸네일 카드 8개씩 + 더 보기
- 카드를 누르면 선택 표시되고 바로 아래 수정 칸이 열려요. 카드의 메일·팩스·카톡 표시가 초록이면 그 방법으로 보낼 수 있어요.

## 로그인 · 계정 (마스터 1명 + 직원 최대 10명)
- 앱을 열면 로그인 화면이 나와요. 처음 한 번은 **연결 주소 바꾸기**를 눌러 웹 앱 주소를 넣어요.
- **마스터**: 아이디 `admin`, 비밀번호는 setup 실행 때 로그에 나온 API_KEY (스크립트 속성 API_KEY에서 바꿀 수 있음).
- 마스터 로그인 후 오른쪽 위 이름 → **계정 관리**에서 직원 아이디·비밀번호·권한(발주·총정리 / 생산 일정 / 공장 정산 / 거래처원장 / 입금 관리 / 카드·경비 / 세금·간편장부 / 거래처)을 정해요.
- 직원 계정은 시트에 보이지 않는 스크립트 속성(USERS)에 비밀번호 해시로만 저장돼요. 사용 중지·비밀번호 변경 시 그 계정의 기존 로그인은 바로 끊겨요.
- 권한 없는 기능은 서버에서도 막혀요. 카드·경비 / 세금 권한이 없는 직원에게는 경비 내용이 내려가지 않아요.
- 마스터는 계정 관리 맨 위 **마스터 정보 바꾸기**에서 아이디·비밀번호·관리자 휴대폰·복구 메일을 바꿔요 (지금 비밀번호 필요, 바꾸면 복구 메일로 알림).
- 마스터 비밀번호를 잊으면 로그인 화면 **관리자 비밀번호를 잊으셨나요?** → 마스터 아이디 또는 휴대폰 번호 → 복구 메일로 6자리 코드(10분 유효, 5번까지 입력, 1시간 3번까지 요청) → 새 비밀번호. 로그인은 5번 틀리면 10분 잠겨요.
- 메일도 못 받는 비상시: Apps Script 편집기에서 `resetMasterToApiKey` 실행 → admin + API_KEY로 돌아감.
- 마스터는 오른쪽 위 이름 → **접속 기록**에서 누가·언제·무엇을 입력/수정/삭제했는지 봐요 (수정은 이전 → 변경, 로그인 실패 포함, 비밀번호는 기록 안 함). 시트의 '접속기록' 탭에도 쌓이고 최근 2만 줄을 보관해요.
- 마스터 → **데이터 시트 연결**에서 총정리 구글 시트 주소를 넣으면 그 시트에서 데이터를 가져오고 저장해요 (마스터 비밀번호 확인, 총정리 탭 검사, 앱 탭 자동 생성, 복구 메일 알림). Apps Script를 배포한 계정이 그 시트의 편집자여야 해요. 직원에게는 이 화면과 시트 링크가 보이지 않아요.
- 코드를 바꾼 뒤 처음에는 Apps Script에서 setup을 한 번 실행해 "다른 시트 열기" 권한을 허용해 주세요.
- **불량·클레임** 탭: 납품 후 불량을 접수하고 매출처(재납품·할인/보상·반품, 수정세금계산서)와 매입처(책임 공장 청구) 조치를 기록해요. 저장하면 총정리에 [클레임 차감]·[재납품]·[클레임 청구] 줄이 생겨 원장·미수·간편장부·부가세·공장 정산에 자동 반영되고, 시트 '클레임' 탭에 기록돼요. 권한 카테고리 "불량·클레임"이 새로 생겼어요.
- 세금 계산 탭은 기본이 **법인**이에요 (사업자 구분에서 개인으로 바꿀 수 있음). 법인세 = 매출 − 매입 − 카드·경비 − 직접 넣는 비용(급여·상여·4대보험·여비 등, 매월/연간) ± 영업외수익, 접대비 한도 초과·이월결손금·세액공제 반영, 2026 사업연도부터 10/20/22/25%, 지방소득세 10%.
- 클레임 차감(마이너스 매출)은 거래처원장·미수에 마이너스 줄로 들어가요. 고객이 차감 후 금액을 입금하면 은행 맞추기가 원 주문 + 차감 줄을 함께 찾아 상계해요.
- 실데이터 시트(리손 테스트 1006)는 '2026년' 탭을 총정리로 자동 인식해요. 입금·지급·계산서 기록은 시트에 있는 값만 써요(추정해서 채우지 않음).
- 출고일 칸이 날짜가 아닌 값('26/03', 2606, 글자)은 출고일로 쓰지 않고 총정리에 '시트: 26/03 · 날짜 확인'으로 표시해요.
- 공장 정산 상세(매입처 원장)는 창 안에서 이번 달·지난 달·올해·전체·월 선택으로 바로 기간을 바꿀 수 있어요.

## 영업 담당자별 매출
- 거래처 탭 → 매출거래처 정보에서 **우리 영업 담당자**를 정해요(엑셀 올리기의 `영업담당` 열로 한꺼번에 넣어도 돼요). 시트 `거래처` 탭 맨 끝에 `영업담당` 열이 자동으로 생겨요.
- 대시보드 → **영업 담당자별 매출** (또는 순위 팝업의 「영업 담당자별」): 담당자별 매출·비중·누적·건수·거래처 수·마진, 담당자 줄을 누르면 맡은 거래처별 매출과 담당 내 비중이 펼쳐져요.
- 엑셀 받기: `담당자별`, `담당자-거래처` 두 시트. 담당자를 안 정한 거래처는 「(담당자 미지정)」으로 맨 아래에 모여요.
- 순위 팝업은 기본으로 **원형(도넛) 그래프**로 비중을 보여줘요(상위 10곳 + 그 외, 조각·범례를 누르면 해당 업체/담당자로 이동). 오른쪽 위 「막대」로 바꿀 수 있어요. 영업 담당자별에서 담당자를 펼치면 그 담당자의 거래처 비중 원형 그래프가 아래에 하나 더 나와요.

## 매출 입력 필요 (매입만 있는 주문)
- 총정리 맨 위 **빨간 칸**에 매출 금액이 한 줄도 없고 매입만 있는 주문을 따로 모아요(아래 일반 목록에서는 빠져요). 처음엔 5건, 「모두 보기」로 전체.
- 「매출 입력」을 누르면 그 주문이 발주 수정 화면으로 열리고 매출 단가 칸에 바로 커서가 가요. 저장하면 빨간 칸에서 빠져요.
- 상태 필터 「⚠ 매출 없음」을 고르면 일반 목록 형태로도 볼 수 있어요.

## 업체 담당자 · 내부 담당자 → 매출 연결
- 매출거래처 정보: **업체 담당자**(상대 회사) / **내부 담당자 (우리 영업)**.
- 발주 입력에 **내부 담당자** 칸: 업체를 고르면 그 거래처의 업체 담당자·연락처와 기본 내부 담당자가 표시돼요. 비우면 거래처 기본 담당자를 따라가고, 이 주문만 다른 사람이면 적으면 돼요(시트 총정리 탭에 `영업담당` 열 자동 추가).
- 총정리: 내부 담당자 필터 + 업체명 밑에 담당자 표시, 엑셀에 「내부 담당자」 열. 거래처원장: 귀사 담당 / 당사 담당 줄.
- 담당자별 매출 통계는 발주 줄의 담당자 기준(거래처 담당자가 바뀌어도 지난 매출은 그때 담당자로 남아요).

## 매출 미입력 대시보드 · 월별 표
- 순위 팝업 「⚠ 매출 미입력」(대시보드 「⚠ 매출 미입력 업체별」 버튼): 업체별 미입력 주문 수 · 매입 줄 · 매입금액 · 비중(원형) · 주요 매입처 · 최근 발주, 펼치면 주문별 「매출 입력」. 엑셀 2시트.
- 매출처 순위에는 업체 옆 「미입력 N」, 매입처 순위에는 「매출 미입력분」 열, 위쪽에 빨간 「⚠ 매출 미입력 N건」 칩.
- 월별 표: 매출 · 매입 · 마진(율) · 월말 총미수잔액 · 매출 미입력(매입금액·건수·업체 수) + 연 합계. 달을 누르면 업체별 미입력 합계가 펼쳐져요.

## 입금 관리 목록 보기
- 미입금 건 입금 처리 · 은행 맞추기 미입금 내역 모두: 업체 선택은 그대로 + **검색**(업체명·품목·금액) + **10/30/50/100개 보기**, 넘치면 아래 숫자 탭(‹ 이전 · 1 2 3 … · 다음 ›). 보기 개수는 기기에 기억돼요.
- 표 맨 위 체크박스로 이 페이지 전체 선택, 다른 페이지로 넘어가도 선택은 유지돼요.

## 포인트 색 직접 고르기
- 포인트 색 창 아래: **◎ 색상판**(원형 판을 누르거나 끌기 + 밝기), **HTML 코드**(#RRGGBB 입력), **🖼 이미지에서**(로고·사진을 불러와 원하는 곳을 누르면 그 색, 많이 쓰인 색 6개도 자동 추천), **💧 화면에서 찍기**(크롬·엣지에서 화면 아무 곳이나 스포이트).
- 고른 한 색으로 버튼·위쪽 띠·배경 톤·차트 색(밝게/어둡게 모두)을 자동으로 만들고, 너무 밝은 색은 흰 글씨가 읽히도록 버튼 색만 조금 진하게 맞춰요. 「내 색」으로 저장돼요.

## 클레임 처리 보고서
- 클레임을 새로 저장하면 A4 **품질 클레임 처리 보고서**가 바로 열려요(카드의 「📄 보고서」로 언제든 다시). 회사 로고(설정의 로고)·회사 정보·결재란(작성/검토/승인)·문서번호(CR-연도-순번).
- 내용: 기본 정보(거래처·담당자·품목·규격·납품 수량·출고일·책임처·원 매출) / 불량 내용·불량률 / 처리 내역(매출처 재납품·차감·수정계산서, 매입처 청구) / 손익 영향(매출 차감+재생산비−공장 청구=순 손실) / 원인 분석·재발 방지 대책 / 진행 경과.
- 「원인·대책·결재 쓰기」로 원인·대책·작성자·검토자를 적어 저장(시트 클레임 탭에 열 자동 추가). 비워 두면 손으로 쓸 줄이 인쇄돼요.
- 확대·축소(−/＋/맞춤/100%, Ctrl+휠), ‹ › 로 다음 보고서, 이미지·인쇄·PDF 저장. 클레임 탭 「📚 보고서함」은 지금 목록(상태·검색 반영)을 넘겨보기, 「보고서 모아 PDF」는 한 파일로 받기.
- **매출처 보고서**(고객 회신용): 보고서 창 위 「📨 매출처 보고서」 또는 클레임 카드의 「📨 매출처 보고서」. 공장·매입처·재생산비·공장 청구·손익·결재란은 빼고, 수신/발신 · 사과 인사 · 대상 제품 · 불량 내용 · 발생 원인 · 처리 내용(재납품 일정, 보상 금액+부가세, 수정세금계산서) · 재발 방지 대책 · 회사명 (인).
- 「📨 매출처 보고서 받기 + 드라이브 올리기」: PDF를 받으면서 구글 드라이브 거래처 폴더에 자동으로 올리고(보기 링크), 클레임에 회신일·링크를 기록(시트 클레임 탭 `회신일`, `회신링크` 열, 전송기록 탭에도 남음). 「카톡으로 보내기」(링크 포함 메시지)·「메일로 보내기」(PDF 첨부)도 한 번에.
- 클레임 탭 「매출처 보고서 모아 PDF」로 여러 건을 한 파일로.
