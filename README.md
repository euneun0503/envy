# ENVY 식품포장 사이트

식품 포장 비닐·파우치 제작 업체 랜딩페이지입니다.
사진, 품목, 배너, 공지, 팝업, 제작사례, 회사 정보는 **관리자 화면(`/admin/`)** 에서 수정합니다. 코드를 고칠 필요가 없어요.
견적 문의 관리와 접속 통계도 같은 관리자 화면에 있어요.

```
index.html          사이트 본문
assets/style.css    디자인
assets/app.js       데이터를 화면에 그리는 스크립트, 견적 폼 전송, 방문 기록
assets/icons.js     사진 없을 때 쓰는 일러스트
data/site.json      회사 정보 · 연락처 · 문의 받을 이메일
data/banners.json   메인 배너 슬라이드
data/products.json  제작 품목
data/cases.json     제작사례
data/notices.json   공지사항 · 1면 상단 공지 띠
data/popups.json    팝업 배너
images/uploads/     관리자 화면에서 올린 사진이 저장되는 곳
admin/              관리자 화면 (GitHub에 직접 저장)
admin/settings.js   관리자가 저장할 GitHub 저장소 이름
apps-script/Code.gs 문의 기록용 구글 Apps Script 코드
```

---

## 1. GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다. 이름: `envy` (Public)
2. 이 폴더의 파일을 전부 올립니다. 웹에서 올릴 때는 저장소 화면의 **Add file → Upload files** 에 폴더째 끌어다 놓으면 돼요.
3. `admin/settings.js` 를 열어 아래 줄을 본인 저장소로 바꿉니다. (GitHub 웹에서 연필 아이콘으로 수정)
   ```js
   repo: "euneun0503/envy",
   ```

## 2. 사이트 공개 (GitHub Pages)

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch**, Branch: **main / (root)** → Save
3. 1~2분 뒤 `https://euneun0503.github.io/envy/` 에서 사이트가 열립니다.

### 도메인 연결 (광고용으로 권장)
1. 도메인 업체(가비아, 후이즈 등) DNS에 추가
   - `www` → CNAME → `euneun0503.github.io`
   - 루트 도메인 A 레코드 4개: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
2. **Settings → Pages → Custom domain** 에 도메인 입력 → **Enforce HTTPS** 체크

## 3. 관리자 화면 사용

주소: 사이트 주소 뒤에 `/admin/`
예) `https://euneun0503.github.io/envy/admin/`

**처음 로그인 (한 번만)**
1. 로그인 화면의 **GitHub 토큰 만들기** 링크를 누릅니다.
2. Fine-grained token → Repository access: **Only select repositories** 에서 이 저장소만 선택
3. Permissions → Repository permissions → **Contents: Read and write**
4. 만든 토큰(`github_pat_…`)을 붙여넣고 로그인. 토큰은 비밀번호처럼 다른 사람에게 보여주지 마세요.

**메뉴**
| 메뉴 | 할 수 있는 것 |
|---|---|
| 견적 문의 | 문의 목록, 상세, 처리 메모, 처리중/처리 완료 전환 (4번 설치 후) |
| 제작 품목 | 추가·수정, 사진 올리기, **노출 켜기/끄기**, **선택 노출·숨김·삭제**, 카테고리별 순서 변경, 배지, 메인 노출 |
| 제작사례 | 추가·수정, 사진, 노출 켜기/끄기, 선택 삭제, 순서 변경 |
| 메인 배너 슬라이드 | 문구, 배경색, 사진, 순서, **노출 기간 예약** |
| 공지사항 · 상단 띠 | 게시판 공지, 중요 고정, **1면 맨 위 공지 띠**, 노출 기간 예약 |
| 팝업 배너 | 첫 화면 팝업, 이미지·버튼·링크, 노출 기간 예약 (방문자는 '오늘 하루 보지 않기' 가능) |
| 회사 정보 · 연락처 | 업체명, 전화, 사업자정보, 문의 기록 주소, 검색 키워드, 강점 |
| 접속 통계 | 오늘·기간 방문자, 페이지뷰, 문의 전환율, 일별 그래프, 유입 경로, 광고 캠페인, PC/모바일 (4번 설치 후) |

- 저장하면 GitHub에 바로 기록되고 **1~2분 뒤** 사이트에 나타나요.
- 예약 노출은 방문자 브라우저 시간 기준으로 시작·종료 시각에 자동으로 켜지고 꺼져요. 다시 저장할 필요 없어요.
- 안 만드는 품목은 삭제보다 **노출 끄기**를 권해요. 나중에 다시 켜면 그대로 돌아와요.
- 사진은 올릴 때 자동으로 긴 변 1600px로 줄여서 저장돼요.

**사진 크기 권장**: 품목 정사각형 800×800 · 제작사례 4:3 · 배너 1200×800 · 팝업 4:3

**기본으로 들어간 사진**: 일부 품목·배너에는 Pexels 무료 사진(상업적 사용 가능)을 연결해 두었어요. 실제 제품 사진이 아니므로, 직접 찍은 제품 사진으로 바꿔 주세요. 사진이 없는 품목은 일러스트로 보여요.

## 4. 견적 문의 기록 (구글 시트) 설치

문의가 들어오면 구글 시트에 한 줄씩 저장되고, **envy2927@gmail.com, naoky0503@gmail.com** 두 곳으로 알림 메일이 갑니다.
관리자의 **견적 문의** 메뉴에서 목록을 보고, 메모를 남기고, **처리 완료**로 바꿀 수 있어요.
같은 스크립트가 방문 기록도 받아서 **접속 통계** 메뉴에 보여줍니다.

1. envy2927@gmail.com 계정으로 구글 스프레드시트를 새로 만듭니다. 이름 예: `ENVY 견적문의`
2. 메뉴 **확장 프로그램 → Apps Script**
3. 편집기의 기존 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여넣은 뒤 저장
4. 왼쪽 **톱니바퀴(프로젝트 설정) → 스크립트 속성 → 속성 추가**
   - 속성: `ADMIN_KEY` / 값: 관리자 비밀번호 (길고 추측하기 어렵게)
5. 편집기 위쪽 함수 선택에서 `setup` → **실행** → 권한 검토 → 계정 선택 → *고급 → (안전하지 않음)으로 이동* → 허용
   (본인이 만든 스크립트라 뜨는 안내예요. 시트 쓰기와 메일 발송 권한입니다.)
6. **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
7. 사이트 관리자 → 회사 정보 → **문의 기록 주소** 에 붙여넣고 저장
8. 1~2분 뒤 사이트에서 테스트 문의 → 시트에 한 줄 추가 + 두 메일 도착 확인
9. 관리자 → **견적 문의** 또는 **접속 통계** 메뉴에서 4번 비밀번호 입력

**참고**
- 알림 받을 주소를 바꾸려면 Code.gs 맨 위 `NOTIFY_EMAILS` 를 고친 뒤 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**
- 일반 Gmail 계정은 하루 메일 발송 수에 한도(약 100명)가 있어요. 문의 수가 그보다 많아지면 Google Workspace 계정으로 옮기세요.
- 시트에서도 상태·메모 열을 직접 고칠 수 있어요. 관리자 화면과 같은 데이터입니다.
- 문의 기록 주소를 비워두면 예비 경로(FormSubmit)로 메일만 발송됩니다.
- 방문 기록은 시트의 '방문' 탭에 쌓여요. 이름·IP 같은 개인정보는 저장하지 않고, 브라우저마다 임의 번호만 씁니다.
- 광고 링크에 `?utm_source=naver&utm_medium=cpc&utm_campaign=10월` 처럼 붙이면 통계의 '광고 캠페인'에서 구분돼요.
- 방문이 하루 수천 건 이상으로 많아지면 '방문' 탭이 커져 통계가 느려질 수 있어요. 그때는 오래된 행을 다른 시트로 옮기거나 GA4를 함께 쓰세요.

## 5. 광고 전에 할 것

- `index.html` 의 `광고 추적 코드` 주석 아래에 네이버/메타/구글 추적 코드 붙여넣기
- `assets/app.js` 의 `광고 전환 추적` 주석 자리에 전환 이벤트 추가 (예: 메타 `fbq('track','Lead')`)
- 개인정보처리방침 페이지 준비 (구글 시트에 문의자 정보를 보관한다는 내용 포함) (문의 폼으로 개인정보를 받기 때문에 필요합니다)
- 제작사례·공지·팝업의 `(예시)` 항목을 실제 내용으로 교체하거나 숨기기
- 품목 사진을 실제 제품 사진으로 교체
